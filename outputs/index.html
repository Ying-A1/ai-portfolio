02 / working with AI

Claude × Claude Code

我把 Claude 用在问题拆解、表达和方案比较，把 Claude Code 用在读仓库、改文件、跑测试和复核结果。关键不是“让 AI 全部代做”，而是让每一步都留下可检查的证据。

STEP 01

定义问题

先写清目标、约束、输入、完成标准和风险边界，再决定让模型参与哪一段。

STEP 02

装入上下文

把仓库、文档、历史决策、真实样例与当前日志整理成最小可用的上下文包。

STEP 03

小步执行

Claude 负责拆解与表达，Claude Code 负责直接修改文件、运行测试和生成可审阅 diff。

STEP 04

人做复核

检查界面、数据、日志和未覆盖边界，把可靠结论沉淀为下一轮可以复用的上下文。
