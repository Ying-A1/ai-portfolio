01

AI / AGENT / HARNESS

我的理解

AI 的价值不止于生成，
而在于进入一条可验证的任务链。

模型提供理解、推理和候选决策。一次生成只是一种输出，还不能证明任务已经完成。

Agent 在环境中推进得到授权的任务，读取结果并更新下一步，让推理真正进入行动。

Harness 把概率模型放进确定性外壳：保留状态、限制权限、验证结果，并在失败时恢复或交给人。

HONEST SYSTEM / 我的判断

系统应区分已确认、未确认与未覆盖。诚实不是语气，而是证据、权限和责任边界可追溯。

Slide Studio

单文件、零运行时依赖的 HTML 幻灯片编辑器。生成后仍能在浏览器里编辑、重排并导出，让 AI 产物继续进入人的工作流。

SLIDESTUDIO
REAL INTERFACE / 1280 × 72001 · GENERATE

01 / 04 浏览器里的真实编辑界面

  1. 01 / GENERATE

    先生成一个
    独立的 HTML Deck。

    从结构和内容出发，得到可以直接打开的单文件幻灯片。

  2. 02 / EDIT

    生成之后，
    仍然可以继续编辑。

    在浏览器里修改文字、布局与视觉表达，不把第一次生成当成终稿。

  3. 03 / ORGANIZE

    把页面重新组织成
    完整的叙事。

    重排、增删和复制页面，让结构跟着人的判断继续变化。

  4. 04 / EXPORT

    带着修改结果，
    回到交付。

    导出修改后的干净文件，把 AI 生成接进真实工作流。
